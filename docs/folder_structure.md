**docs/ Folder Structure**

Here’s a future‑proof documentation structure that scales as the project grows.

You can create this as:

```bash

docs/
│
├─ index.md
├─ installation.md
├─ quickstart.md
├─ concepts/
│   ├─ overview.md
│   ├─ self_healing.md
│   ├─ localization_engine.md
│   └─ file_structure.md
│
├─ guides/
│   ├─ adding_languages.md
│   ├─ syncing_languages.md
│   ├─ ui_texts.md
│   └─ templates.md
│
├─ api/
│   ├─ engine.md
│   ├─ localizer.md
│   ├─ template_localizer.md
│   └─ ai_translation.md   # reserved for v0.2
│
├─ examples/
│   ├─ basic_ui.md
│   ├─ basic_templates.md
│   ├─ sync.md
│   └─ full_demo.md
│
└─ roadmap.md
```
